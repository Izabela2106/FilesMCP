# Context docs

This project uses Model Context Protocol (MCP) for filesystem operations. Its purpose is to use natural-language commands to manipulate files by combining low-level MCP operations into tools that are easier for a model to use.

## Files in this folder

| File | Role |
|------|------|
| `project-overview.md` | Goals, agent config, native tool contracts |
| `ai-workflow-rules.md` | How to implement features against these specs |
| `progress-tracker.md` | Completed work and next steps |
| `1.md` | Scratch / task notes |

For setup and how to run the agent, see the root [`README.md`](../README.md).
